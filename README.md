## 🚀 Deployment & Custom Domain Setup (GitHub Pages)

1. Push this repository to GitHub under `https://github.com/urmiurmasnigdha/urmiurmasnigdha.github.io` or `urmi-portfolio`.
2. Go to **Settings > Pages** on GitHub.
3. Select **Source: Deploy from a branch** (`main` branch, root `/`).
4. In **Custom domain**, enter: `urmiurmasnigdha.com`.
5. Check **Enforce HTTPS**.
6. Point your Domain DNS (e.g. Namecheap, GoDaddy, Cloudflare) to GitHub Pages:
   - **Apex A Records (@)**:
     - `185.199.108.153`
     - `185.199.109.153`
     - `185.199.110.153`
     - `185.199.111.153`
   - **CNAME Record (www)**:
     - `urmiurmasnigdha.github.io`
